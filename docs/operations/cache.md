# 缓存与残片

`temp/`既是下载缓存，也是中断恢复和待补传依据。它不是随时可以清空的临时目录。

## 三类本地内容

| 分类 | 示例 | 自动清理 |
| --- | --- | --- |
| 可恢复 | aria2控制文件、已验证分P、完整本地成品 | 禁止随意清理 |
| 待补传 | 下载完成但AList未最终确认 | 所有目标确认后清理 |
| 待清理残片 | `_invalid`、无法识别旧残片、历史凭据目录 | 仅在页面预览和二次确认后 |

只有有效成品、可继续的aria2控制文件或可确认原始轨道才算“可续传”。失败会话若没有有效分P也没有aria2数据，不会显示为可续传。

## 缓存软上限

默认10GB。达到上限时只暂停启动新下载，上传、远端确认和上传后清理继续运行；释放空间后调度器自动唤醒下载。

缓存占用、可续传会话和残片分类由后台异步扫描统一计算，最多并发检查4个顶层目录，并共享10秒快照。扫描失败时保留上一次完整结果；首次结果尚未生成且设置了缓存上限时，会保守暂停新下载。

## 安全清理

优先使用Web面板“清理数据”查看分类、大小和影响范围。活动会话、可恢复缓存和有效旧成品不会被残片清理自动删除。不要在容器运行时直接执行`rm -rf temp`。

## 下架封面回填

下架清单不会等待网络封面。启动后BFB先把已经存在的`covers/<BVID>.webp`重新关联到SQLite，再以单并发、最短2秒间隔补齐仍缺失的历史封面；正常收藏夹同步产生的封面任务始终优先。

回填只接受B站HTTPS图片域名和图片响应，单张最多8MB、单次最多10秒。完成摘要保存在SQLite的`schema_meta`中，终止失败不会在每次启动无限重试；完整状态或封面迁移导入后会重新检查。

封面转换的ffmpeg最长运行15秒。清理封面缓存或替换业务SQLite前，BFB会停止回填并等待整个封面队列空闲；30秒内未能停止时拒绝清理或导入。封面清理成功后会删除一次性回填标记并重新启动低速检查，不会让旧任务在新数据库上继续回写。
