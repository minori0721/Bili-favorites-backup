# 订阅 UP 投稿

首页的 **UP 订阅** 可以持续归档指定 UP 的公开视频。订阅与收藏夹分开管理，但使用同一套下载、上传、核验和恢复队列。

## 添加订阅

点击 **添加订阅**，选择一个已登录的 B站账号，然后通过下列入口找到 UP：

- **我的关注**：浏览或搜索该账号的关注列表。
- **搜索 UP**：按名称和关键词搜索，不要求已经关注。
- **UID / 链接**：输入 UID 或 `https://space.bilibili.com/UID` 主页链接。

选择 UP 后设置归档范围：全部投稿、从现在开始、从日期开始、从某个视频开始，或只归档选中的视频。日期和视频起点均包含边界当天或同一发布时间的投稿。“从视频开始”一次选择一位 UP。

历史投稿会分批扫描，列表不会立即显示全部历史。B站请求串行执行，遇到风控会冷却后再试，避免连续重试。

## 投稿选择和归档库

**投稿选择** 展示本地已发现的投稿。搜索、筛选和分页不会向 B站发请求；**刷新投稿** 会安排后台扫描。

“只归档选中的”模式下，勾选视频并点击 **归档选中**，才会进入备份队列。其他模式也可以单独选中范围之外的视频。取消单独选择会恢复原归档规则，不会删除已有文件，也不会解除明确设置的排除。订阅暂停时，符合规则的视频仍须等订阅恢复后才归档。

归档库增加 **UP 订阅** 目录。未选择候选不计入实际归档；同一个 BV 在多个来源中出现时，全库仍只显示一张视频卡片。已有完整、有效的归档会复用，不重复下载。

投稿卡片的 **播放** 读取这个 UP 自己的已归档队列，不依赖之前打开的收藏夹。若当前订阅没有成品，但其他来源保留了同一 BV，会显示 **已有归档**，只打开该视频的有效归档。退出播放器可回到投稿选择；准备来源时关闭工作区会取消读取，不会被迟到响应重新打开播放器。

## 删除与排除单个视频

视频的 **管理归档** 始终可用，已排除的视频也保留此入口。卡片分别显示是否可播放和是否已排除；排除不代表文件已经删除。操作提供：

- **保留归档，排除此视频**：保留已有文件和播放能力；以后不再通过所选来源下载、补档或重调这个视频的画质。
- **删除归档，并排除此视频**：先预览引用和文件，再确认删除，并保存这个视频的排除规则。

两种操作都可以选择 **仅当前来源**、**指定来源** 或 **所有来源**。归档库中的收藏夹与 UP 订阅都使用同一个“管理归档”窗口。指定来源只处理勾选的收藏夹或订阅；所有来源也影响以后新发现的来源，直到主动解除全局排除。来源级删除不会移除其他来源仍使用的物理文件。

这里的排除只针对当前 BV，其他视频的归档规则不变。“未排除”不代表来源正在同步，是否自动归档仍由来源是否启用及其归档范围决定。处理整个 UP 的移除请使用订阅卡片右上角的 ×；保留订阅、改为只收新投稿请使用下面的历史清理入口。

确认前会列出受影响和保留的来源名称，并分别显示涉及文件、共享保留、预计实际删除和预计释放空间。同一个 BV 的独立副本与多个来源共用一个物理文件会分别计算。关闭窗口不会取消已经提交的后台清理；删除失败时排除规则仍然有效。

清理失败时排除规则仍然有效，可以重试，也可以 **停止剩余清理**。停止只接受已经退出执行的失败任务，保留尚未删除的文件，不恢复已删除文件；曾尝试删除但结果不明的文件先进行只读核实，核实暂时失败时明确报错，不继续删除。停止成功后可以重新设置归档规则。运行中的请求须先结束，关闭窗口不等于停止清理。

恢复分两种：**恢复归档此视频** 将这个视频加入单独选择；**解除排除，按来源规则** 只清除排除，“只归档选中的”模式不会因此自动选中。两者都遵守订阅启用状态；清理未结束前不能绕过守卫恢复。解除全局排除不会同时解除当前来源自己的排除，需要分别处理。

## 清理历史归档，继续订阅新投稿

在 **投稿选择** 中点击 **清理历史归档**。核对后，订阅保持启用，归档起点改为本次核对时间；更早投稿的单独选择取消，只为本次实际清理的已归档视频保存排除。未备份的历史候选不永久排除，但不会按新的时间范围自动下载。以后仍可主动单独选择。

这不是“删除后再自动补回来”：本次清理的视频明确排除，新投稿按新的起点持续归档。共享文件仍保护其他来源。预览与规则修改、排除保存和任务提交在同一事务中完成，提交失败不会只留下规则变化。

## 暂停、移除与更换账号

暂停订阅不会删除已有归档。点击订阅卡片右上角的 **×**，可以选择：

- **移除订阅，保留归档**（默认）：停止后续订阅，已经备份的视频继续保留。
- **移除订阅，并删除本订阅的归档**：先核对实际视频数、文件数、共享保留数量和预计释放空间，再输入确认文字。只处理这个订阅，其他来源仍使用的文件会保留。

“发现投稿”不是已归档数量。未备份的投稿不会被当作远端文件计算。清理任务显示在首页，即使订阅卡片已移除，刷新页面后仍能查看；失败可以重试，如果文件证明发生变化则先重新核对。完成记录保留在首页一天。

重新添加同一 UID 会复用来源、选择和排除记录，并采用此次设置的归档范围。选择删除时，仅本次清理的已归档视频保存排除，不把“已发现但从未备份”的投稿一起排除；未结束的清理须先完成或停止，再重新添加或解除排除。收藏夹等其他来源的规则不受影响。

可以在 **归档规则与授权账号** 更换请求所用的 B站账号。为避免旧任务写回，需要等当前同步和传输任务完成后再更换；已有归档仍然保留。
