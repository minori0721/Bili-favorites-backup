# 订阅 UP 投稿

首页的 **UP 订阅** 可以持续归档指定 UP 的公开视频。订阅与收藏夹分开管理，但使用同一套下载、上传、核验和恢复队列。

## 添加订阅

点击 **添加订阅**，选择一个已登录的 B站账号，然后通过下列入口找到 UP：

- **我的关注**：浏览或搜索该账号的关注列表。
- **搜索 UP**：按名称和关键词搜索，不要求已经关注。
- **UID / 链接**：输入 UID 或 `https://space.bilibili.com/UID` 主页链接。

选择 UP 后设置归档范围：全部投稿、从现在开始、从日期开始、从某个视频开始，或只归档选中的视频。日期和视频起点均包含边界当天或同一发布时间的投稿。“从视频开始”一次选择一位 UP。

历史投稿会分批扫描，列表不会立即显示全部历史。B站请求串行执行，遇到风控会冷却后再试，避免连续重试。

## 投稿选择和归档库

**投稿选择** 展示本地已发现的投稿。搜索、筛选和分页不会向 B站发请求；**刷新投稿** 会安排后台扫描。

“只归档选中的”模式下，勾选视频并点击 **归档选中**，才会进入备份队列。其他模式也可以单独选中范围之外的视频。取消单独选择会恢复原归档规则，不会删除已有文件。

归档库增加 **UP 订阅** 目录。未选择候选不计入实际归档；同一个 BV 在多个来源中出现时，全库仍只显示一张视频卡片。已有完整、有效的归档会复用，不重复下载。

## 删除与不再归档

视频的 **管理视频** 提供：

- **不再归档**：保存排除规则，保留已有文件和播放能力。
- **删除归档，并不再归档**：先预览引用和文件，再确认删除。

两种操作都可以选择 **仅当前 UP 订阅** 或 **所有来源**。后者也影响收藏夹、手动归档和其他 UP 来源。来源级删除不会移除其他来源仍使用的物理文件。

清理失败时排除规则仍然有效，页面提供重试。解除全局排除不会同时解除当前来源自己的排除；需要分别恢复。

## 暂停、移除与更换账号

暂停订阅不会删除已有归档。点击订阅卡片右上角的 **×**，可以选择：

- **移除订阅，保留归档**（默认）：停止后续订阅，已经备份的视频继续保留。
- **移除订阅，并删除本订阅的归档**：先核对实际视频数、文件数、共享保留数量和预计释放空间，再输入确认文字。只处理这个订阅，其他来源仍使用的文件会保留。

“发现投稿”不是已归档数量。未备份的投稿不会被当作远端文件计算。清理任务显示在首页，即使订阅卡片已移除，刷新页面后仍能查看；失败可以重试，如果文件证明发生变化则先重新核对。完成记录保留在首页一天。

重新添加同一 UID 会复用来源、选择和排除记录，并采用此次设置的归档范围。选择删除时，已发现投稿和已有归档视频会保存本订阅的排除记录，避免重新添加后自动下载回来；清理未完成时须先完成清理，再重新添加或解除排除。收藏夹等其他来源的规则不受影响。

可以在 **归档规则与授权账号** 更换请求所用的 B站账号。为避免旧任务写回，需要等当前同步和传输任务完成后再更换；已有归档仍然保留。
