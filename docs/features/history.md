# 分P历史归档

B站视频的分P可能新增、删除、重排或被替换。BFB恢复未完成的下载时重新获取当前详情，并用CID识别分P身份。已有完整归档仍优先保留，普通同步不会追随源站更新自动替换它。

## 恢复规则

- 相同CID且已验证完整：直接复用。
- 新增CID：只下载缺失分P。
- CID被替换：旧完整分P进入历史，新版重新下载。
- 分P被删除：旧完整分P进入历史。
- 仅顺序变化：按CID重新对应，不重复下载。

这次恢复完成后，新下载的版本保存在正式目录，恢复过程中替换或移除的旧分P保存到：

```text
_history/<快照时间>/
```

历史上传失败不会阻止最新版目标完成，但历史文件会继续以较低优先级补传。最新版与历史文件全部确认前，本地目录不会清理。

## 视频完全下架

如果当前视频已经不可访问，但本地存在经过验证的部分旧内容，系统可归档这部分文件并显示“部分备份”。无法验证的残片只进入清理预览，不会自动上传或删除。

::: info 已归档内容不会被B站更新覆盖
已有完整归档按原样保留；中断恢复产生的旧分P保存在`_history`。需要主动更换已归档画质时，使用[画质重调](./quality-upgrade)。
:::
