# 异常熔断与恢复

BFB把B站下载接口健康和 AList / OpenList WebDAV 上传健康分开管理。任一侧异常时只暂停会扩大故障的工作，已经拿到下载地址的 aria2 传输不会被无关熔断中断。

待处理中心只显示需要管理员决定的事项。没有这类事项时，中心会直接显示空状态，不额外占用一行“自动复核中”提示；后台复核仍会继续运行，新的人工事项出现后才会重新显示摘要。

## 远端 WebDAV 异常

认证、权限、驱动或持续网络故障会触发上传熔断，并暂停启动新下载，避免本地缓存持续堆积。失败文件保留在`temp`，远端后端恢复后进入持久补传流程。

单个确定性失败会隔离到自己的补传任务，不会永远卡住其他视频。AList / OpenList 返回405时，BFB会先复核文件是否已经按预期大小落盘：落盘一致才确认成功，否则根据发生阶段区分临时上传会话异常和真实驱动错误。

认证、权限或地址异常时，“检查存储配置”会回到全局设置并聚焦“只读检查存储连接”。该检查使用当前草稿，最多等待15秒，只读取WebDAV端点和归档目录，不保存配置、不写测试文件，也不承诺账号具备写入权限。

## 什么时候需要选择

- 远端暂时不可见会先自动复核；至少3次独立观察且持续30分钟后才进入人工待处理。
- 未知同大小、异大小或多分P混合状态不会覆盖正式路径。异大小冲突、多分P混合状态以及达到3次/30分钟门槛的长时间不可见，会在本地整组文件和候选父目录安全时自动生成`_conflicts`候选；只有完整旧档和完整候选并存时才再选择保留哪一份。候选本身失败后会停止自动生成，回到待处理中心，避免重复创建远端副本。
- 可恢复的下载达到重试上限后，可继续当前账号、先验证另一个已登录账号，或暂缓24小时。明确下架或不可用不会伪装成普通重试任务：收藏夹首次报告失效时先进入待确认，两个详情接口都给出明确不存在证据后才停止当前下载，并按1天、7天、30天低频复核后休眠。休眠不要求人工放弃；收藏夹重新可见或相关账号重新登录后会自动唤醒，已有归档与封面始终保留。
- 视频详情的临时超时、5xx、未知业务码或空分P只表示“暂时无法确认”，按10分钟、1小时、6小时、24小时、7天退避后休眠，不会被猜成已删除。视频源状态不会进入待处理角标；详情中的“立即复核”只唤醒同一个持久探测任务，没有可用账号时会提示先登录或启用账号。
- 画质重调只有在失败发生于下载或暂存上传、证据明确指向媒体规格/单文件限制且正式替换尚未开始时，才允许重新选择画质与编码生成独立版本。选择器先列出所有分P共同可用的组合和预计空间；替换和旧文件清理失败只恢复原阶段。

严格媒体重试不会把 BBDown 的“已选择流”日志当成成功证明。选择行只用于在明确选中错误档位或编码时提前停止；B站画质档位由持久下载清单逐分P核对，实际编码最终由每个分P的 `ffprobe` 决定。调度器创建上传任务前，以及 `UploadTask` 发出第一条 WebDAV 请求前也会再次核验。请求规格不匹配或证明无法确认时，候选保持失败并进入待处理，原归档证明、本地原文件和收藏关系不变。

这些操作都不会修改全局编码偏好。旧档不完整时自动采用已验证候选，候选不完整时自动保留完整旧档；完整旧档与完整新候选仍由用户选择，另一份远端文件不会自动删除。

## B站风控

网页接口收到`v_voucher`稳定信号后：

1. 保留下载会话和已完成内容。
2. 全局停止启动新BBDown任务3分钟。
3. 冷却结束只放行原失败任务探测。
4. 有APP token时临时用APP接口；没有则继续Web单任务探测。
5. 收到播放地址就恢复健康，不等待整段视频下载结束。

探测再次触发风控会重新冷却固定3分钟，不指数延长。用户选择常驻APP模式时，所有新任务使用APP接口。

启动、数据库重新绑定、周期复核和打开待处理中心会检查现有上传会话是否缺少对应任务，并按`sessionId + generation`补建唯一恢复任务。该投影仍使用现有`jobs`表，不创建第二套任务系统；已验证或已替代的会话不会重新出现。

恢复投影按页读取传输会话，不会因为前面的活动任务很多就永远漏掉后面的孤儿会话。多分P候选会明确显示“部分分P”和已确认数量；已确认分P不会重复上传，剩余分P在同一候选代次中继续恢复。页面投影只读取SQLite，不同步阻塞检查本地视频文件，真正执行恢复前才做本地清单、大小和证明复核。

待处理中的候选可以选择“放弃本次候选”。这个动作只结束当前候选的调度生命周期并保留审计信息、本地文件、隔离远端文件和原归档证明，不会自动删除任何远端文件。已放弃候选不会在每轮同步中重新刷出；以后视频再次需要归档时仍会创建新的候选代次。旧版下载失败也会投影到同一个待处理中心，只有用户明确放弃后才停止继续提示。

## 容器重启

SQLite任务、冷却截止时间和下载会话都持久化。异常退出依靠任务租约过期恢复；正常SIGTERM/SIGINT会停止领取任务、终止BBDown/aria2并等待最多20秒落盘。
