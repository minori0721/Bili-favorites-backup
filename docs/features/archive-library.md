# 本地归档库

从桌面侧栏或手机底部导航进入“归档库”，也可在概览中点击“打开归档库”。目录、搜索和翻页读取`data/bfb.sqlite`与当前账号配置，不临时查询 B站元数据。目录图片优先读取本地图片缓存；缓存未命中时只下载已知地址的图片，不额外查询 B站接口。播放准备在后台只读访问远端存储，不改变归档列表和核验状态；来源删除仍须经过核对与确认。

## 目录范围

![当前开发版归档库：来源目录、搜索筛选与可播放视频，使用隔离演示数据](/screenshots/archive-library.jpg){.doc-shot}

左侧目录固定包含：

- **全部归档**：当前配置中所有账号的本地关系，按BV号合并。
- **UP 订阅**：浏览对应 UP 的实际归档，默认按视频发布时间从新到旧排列。
- **该账号全部**：只聚合一个账号，重复BV仍只显示一次。
- **当前同步收藏夹**：保留B站收藏顺序，已经移出的历史关系放在当前关系之后。
- **已停用归档**：SQLite仍有关系、但当前不再选择同步的收藏夹，折叠显示；可从目录右侧 `⋯` 清理该来源的归档。
- **已移除账号**：账号登录信息已经移除，但本地证明和归档仍保留；同一UID重新登录后会恢复为当前账号。

目录的收藏夹封面和 UP 圆形头像使用真实身份和已有图片缓存。旧收藏夹没有缓存封面时，使用已有视频缩略图；无可用图片则显示目录图标。打开 `⋯` 可查看目录统计，或访问对应 B站收藏夹 / UP 主页。

### 清理停用收藏夹

先取消选择该收藏夹的同步，再从“已停用归档”的 `⋯` 选择“清理此来源归档”。核对文件数、预计释放大小和共用文件数，输入确认文字后提交。其他收藏夹或 UP 订阅仍在引用的文件会保留；只清理该来源，没有文件的旧索引不需要连接网盘。

清理期间目录保留并显示进度，完成后才移除。失败时可重试、重新核对范围或停止剩余清理；尚未完成或停止前不能重新启用该收藏夹。已经删除的文件不会因停止操作而恢复。之后主动重新选择收藏夹同步时，可重新发现并归档视频。

已选择但尚未扫描的收藏夹也会出现，显示 0 个视频；没有扫描记录时不显示更新时间。仅移除账号登录不会删除B站Cookie之外的归档索引，已移除账号仍可搜索和播放；账号快照只保存UID、名称、头像和移除时间，不保存Cookie、Token或APP身份。

目录摘要只显示视频数、可播放数和索引更新时间；页头的“目录统计”可查看完整更新时间、来源文件引用数和不同存储路径数。文件统计在展开时读取当前目录，不随搜索结果变化；计算期间显示等待，失败时可单独重试，不会被显示为 0。切换目录、刷新索引或退出后不会使用旧请求结果。同一视频可以有多个分P或文件，共享文件也可能被多个来源引用，因此这些文件统计不等于视频数；更新时间不代表备份完成，统计也不是实时远端扫描结果。

桌面端采用左侧目录与右侧封面网格的全屏工作区。手机先显示带封面摘要的目录，再进入两列视频网格；返回目录和关闭工作区都会保留适用的滚动位置。浏览偏好只在当前浏览器保存目录、筛选、排序和滚动位置，不保存搜索词。

## 搜索、筛选与排序

每批最多读取50个BV，滚到底部后继续追加，不会清空已加载卡片。搜索覆盖当前保存的标题、归档前标题、UP主和BV号；空格分隔的多个词采用AND匹配，`%`和`_`按普通字符处理。

搜索默认限制在当前目录，也可以切换为跨账号“全部归档”。状态筛选含义如下：

| 筛选 | 含义 |
| --- | --- |
| 全部 | 当前范围内所有本地关系 |
| 可播放 | 至少有一份可直接播放的已验证成品 |
| 待处理 | 没有可播放成品，但仍在发现、排队、下载、上传或远端确认阶段 |
| 异常 | 没有可播放成品，且当前为失败、远端缺失、充电限制、失效或无兼容媒体 |
| 「留存」 | B站源已失效或不可用，但仍有已验证、可播放的归档；与“可播放”可重叠 |
| 已删除 | 只显示手动删除留痕，不进入普通搜索或播放队列 |

具体收藏夹的默认顺序是当前关系按收藏顺序在前，历史关系按最后发现时间倒序在后。UP 目录按视频发布时间从新到旧排列，缺少发布时间的历史归档放在末尾；账号与全局聚合默认按BV最近一次发现时间倒序。也可以按归档标题正序或倒序。

收藏关系、归档文件或手动删除状态变化后，目录和视频列表会刷新对应记录；普通收藏、手动归档和 UP 订阅分别保留各自来源。

## 卡片与来源

卡片封面优先使用BFB本地缓存，失败后尝试SQLite保存的原始封面，最终显示固定占位。卡片同时显示归档前标题、UP主、BV号、状态、分P或已确认实际画质，以及最多三个收藏夹来源摘要。

BV／AV 编号可以在新标签页打开 B站原视频，也支持右键复制链接。封面和标题仍打开归档播放或来源详情；点击编号不会播放归档。UP 投稿目录、收藏夹视频详情和在线内容使用相同的编号链接。

已知 UID 的视频作者名字也可打开对应 B站主页。缺少 UID 的历史记录仍显示普通文字，后续正常扫描取得 UID 后再显示链接；不会按名字猜测，也不会为显示链接逐项请求 B站。联合投稿使用视频实际作者的 UID，可能与当前订阅的 UP 不同。

聚合范围内同一BV只显示一次，但不会合并或删除底层收藏关系。不可播放卡片打开来源详情，列出账号、收藏夹、当前或历史关系、最后发现时间和脱敏错误摘要；响应不会包含 AList / OpenList 真实路径、账号密码、B站Cookie或网盘签名地址。

## 从归档库播放

进入归档库后会提前加载播放器，并按实际存储目录准备目录清单，当前浏览的来源优先；共用文件所在的目录只处理一次。后台每次处理一个目录，完成后间隔两秒，离开归档库或隐藏页面会停止尚未执行的准备。列表可以立即浏览；网络或存储异常会暂停本轮预热，实际播放时仍可重试。

目录清单继续使用 AList / OpenList 自身的缓存和过期策略。带有明确到期时间的播放链接在 BFB 内存中限量复用，临近到期时重新获取；播放后按需要准备下一分 P 或下一条视频的链接。准备过程不下载视频正文，不会为了保活而持续刷新网盘。存储配置、文件身份或可播放状态变化后，旧缓存不再使用。

播放器分别显示控件加载、播放地址获取和视频缓冲阶段，等待时显示秒数。缓存链接连接失败会重新获取一次，再沿用已有的代理回退；浏览器解码限制仍按媒体格式处理。

可播放卡片直接进入归档播放器。连续队列沿用打开时的目录、搜索、状态和排序，并跳过不可播放项目。播放器中的搜索在当前范围内进一步筛选，清除后恢复原库队列；滚动时按需加载相邻页面。

同一BV存在多份已验证成品时，BFB依次比较：

1. 所有分P都已有实际尺寸时，最低短边更高者优先。
2. 实际帧率更高者优先。
3. 完整备份优先于部分备份。
4. 已验证分P更多者优先。
5. 最近确认者优先，最后使用稳定来源键打破平局。

来源优先级按实际检测结果确定。当前来源失效后，可手动重试并选择其他仍有效的来源。

## 删除具体来源

卡片的更多操作会打开来源详情。以下来源允许删除：

- 已移出当前收藏夹的历史关系。
- 已停用收藏夹中的来源。
- 已移除账号保留的来源。

每个来源提供“管理归档”，可停止当前来源、指定来源或所有来源的自动归档，并选择保留已有文件或删除已验证归档。活动收藏夹也能使用此入口，明确保存排除规则，避免下一轮自动下载回来。预览分别列出涉及文件、共享保留、预计实际删除和释放空间；涉及远端删除时输入 `DELETE ARCHIVE` 后开始后台任务，关闭窗口不会取消清理。

历史、停用来源仍保留“删除本次归档”：只删除所选来源的当前归档，不新增永久排除；以后重新加入活动来源时仍可重新归档。活动收藏关系不能绕过排除步骤直接删除。

BFB会在整项删除开始前核对来源、归档目录、文件类型与大小，并检查关联任务；发现冲突时暂停并说明原因。其他来源共用的文件保留，只移除当前来源的关联；原本不存在的文件记入清理结果。清理只处理登记的文件，任务完成后可能留下空目录，可在 AList / OpenList 中确认后处理。

任务使用 SQLite 租约和逐文件进度，容器重启后从最后确认项继续。401、403、路径或大小冲突会等待人工处理；超时和5xx经过1分钟、10分钟、1小时退避后转为手动重试。远端连接、归档路径或本地证明已经变化时，请使用“重新预览并确认”，旧失败记录仍保留作审计。

清理失败、当前请求结束后，可选择“停止剩余清理”。核实已尝试删除的文件后，会保留剩余文件和排除规则，并更新数量和空间统计；已删除文件不会恢复。暂时无法核实时，按提示稍后重试。

已排除的视频仍保留“管理归档”。UP 的恢复可以选择将视频加入单独选择，或仅解除排除并遵循原范围；收藏夹仍按启用和同步范围工作。清理未结束时，这些入口与批量选择共用相同守卫。

清理期间，该来源暂停归档；共享任务中的其他来源继续运行。

清理完成后，目标来源从普通列表、搜索、远端验证和播放队列排除；如果同一BV还有其他成品，卡片会自动切换到最佳来源。没有其他来源时只在“已删除”筛选保留标题、封面、来源、删除时间、文件数和空间。以后视频重新加入活动收藏夹时，删除留痕会转为恢复状态并按正常流程重新归档，不形成永久排除。

## 功能边界

归档库不提供移动或远端全盘扫描；删除仅处理经预览核对的归档文件，所有来源模式仍保护范围之外的文件。B站在线收藏夹、订阅合集、追番追剧、稍后再看和历史记录请使用[在线内容](./online-content)；在线内容的读取不会改变普通同步周期。
