# 归档播放器

BFB可以在收藏夹“查看详情”中直接播放AList里的已验证归档。点击可播放行或使用键盘`Enter`、`Space`即可打开；桌面端悬停或键盘聚焦时会显示播放标记，触屏设备不常驻显示遮罩。

## 可播放条件

播放器只接受以下内容：

- 收藏关系状态为“已备份”或“部分备份”。
- 远端文件已经通过BFB最终确认，而不是“上传确认中”。
- 文件容器为MP4、M4V或WebM。

待下载、待补传、上传确认中、远端缺失和下载失败项目不会开放流地址。历史关系可以从详情中单独播放，但不会进入当前收藏夹的连续队列。

## 顺序与分P

播放队列只包含当前仍在收藏夹中的可播放视频，顺序与收藏夹一致。多P优先使用归档时保存的分P序号；旧记录缺少序号时再解析文件名中的`_P<number>`，最后使用自然文件名顺序。

默认会从当前分P继续到下一P，并在一条视频结束后进入收藏夹下一条可播放视频。可以在播放器中关闭“连续播放”。上一项、下一项、分P按钮和右侧编号队列都不会改变收藏夹或远端文件。

## 浏览与搜索

右侧队列每批从SQLite读取50项。滚到列表顶部或底部会继续读取相邻页面，因此收藏夹可播放视频不会被限制为50项；已加载页面会在本次播放器会话中缓存。

搜索框覆盖当前收藏夹全部可播放归档，可按视频标题、归档前标题、UP主或BV号查找。空格分隔的多个词需要同时匹配。搜索只负责定位：输入不会暂停当前视频，选择结果后会清空搜索并回到该视频在完整收藏夹中的位置，随后仍按原收藏顺序连续播放。

队列缩略图优先读取BFB本地封面缓存，失败后尝试原始封面，最终显示低对比度占位。封面使用固定尺寸和懒加载，不会在加载时改变队列行高。

## 横屏、竖屏与进度

播放器会根据媒体尺寸识别横屏或竖屏，始终使用完整显示，不裁切画面。桌面端显示播放器与编号队列；窄屏设备改为上方视频、下方信息和队列，支持设备自然旋转，不强制锁定方向。

音量、静音、倍速、连续播放开关和分P进度保存在当前浏览器的本地存储中。进度每5秒以及暂停、关闭时保存，最多保留500条；距离开头不足10秒或距离结尾不足15秒的记录不会恢复。

## 字节流与安全

浏览器始终先请求BFB提供的受保护播放地址。BFB重新校验登录会话、账号、收藏夹、文件ID、关系状态和路径；AList返回不含凭据、非本机或私网的外部HTTPS临时直链时，BFB再用302让浏览器直接连接网盘，从而避免视频字节经过BFB服务器。

无法取得安全直链时会自动回退现有Node流代理。直连和代理都保留单段`Range`、`HEAD`、`206 Partial Content`和`416 Range Not Satisfiable`，因此可以拖动进度。非HEVC直连失败时只自动切换代理一次并恢复当前位置；手动重试会重新获取临时直链。

默认设置为“优先网盘直连，失败自动代理”，也可在全局设置中改为“始终由BFB代理”。直连不会暴露AList地址、账号、密码或真实WebDAV路径，但网盘临时签名地址会在当前浏览器的网络面板中可见，且在过期前可能被直接访问。BFB不持久化或记录该地址。

## 编码兼容性

BFB不转码。H.264通常能在现代浏览器中直接播放；HEVC、AV1及特殊音轨取决于设备、操作系统和浏览器的原生解码支持。遇到HEVC无法解码时，可尝试支持HEVC的Edge、Safari、系统浏览器或AList客户端，也可以在队列中跳过该视频。

播放器读取远端归档，不解析B站在线流，不会绕过B站账号权限或地区限制。
