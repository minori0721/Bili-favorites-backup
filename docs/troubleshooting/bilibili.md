# B站风控与账号失效

## 网页接口触发风控

缓存横条出现“B站触发风控，下载已暂停”时，BFB已进入固定3分钟冷却。不要频繁重启或手动反复触发任务；冷却截止时间持久化，重启不会绕过它。

冷却结束后只会放行一个探测任务。有APP token时临时用APP探测，成功取得播放地址后恢复网页模式；常驻模式不会被自动改成APP。

## 账号失效

账号卡片会显示授权刷新失败或需要重新扫码。处理步骤：

1. 在BFB重新扫码同一UID。
2. 确认账号已启用。
3. 检查APP模式下所有启用账号是否都有access token。
4. 等待相关下载、画质和充电探测任务被唤醒。

删除账号默认选择“仅移除账号登录”，不会删除已确认备份证明、封面或播放能力。依赖该账号的运行下载会安全终止并保留会话；有其他启用账号时自动改派，没有则暂停等待同UID重新登录。归档库会把这类内容放在“已移除账号”下，同UID重新扫码后自动恢复关联。

只有主动选择“删除账号并清理远端归档”、查看预览并输入`DELETE REMOTE ARCHIVE`后，BFB才会建立后台删除任务。任务先停止或改派相关账号工作，只删除SQLite已追踪且远端重新核验一致的文件；共享文件和未知文件不会误删。BFB不删除远端目录，清理后留下的空目录可在AList中人工确认。任务开始后不能取消，失败时可以重试；AList连接或归档路径变化后应重新预览并再次确认。

## 充电视频

显示“充电视频”不是账号故障。试看不等于完整权限，系统不会下载试看冒充备份；默认七日复查，无需手动重试。
