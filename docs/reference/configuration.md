# 配置项

设置页保存到`data/config.json`。旧字段会在加载时迁移；表中的默认值来自v2.5.2代码。

## 调度与缓存

| 配置 | 默认值 | 有效范围 / 说明 |
| --- | ---: | --- |
| 收藏夹轮询间隔 | 10分钟 | 最少1分钟 |
| 同一视频分P间隔 | 15秒 | 不小于0 |
| 下载并发 | 1 | 1至5，建议保持1 |
| 上传并发 | 2 | 1至10 |
| 远端文件上传间隔 | 10秒 | 0至120秒，只限制真实PUT启动 |
| 本地缓存软上限 | 10GB | 0至1024GB |
| 在线缩略图缓存上限 | 256MB | 64MB至2GB；只限制`data/online-covers`，不清理归档封面 |
| 任务预取上限 | 25 | 5至100 |
| 下载重试次数 | 3 | 0至20 |
| 重试基础延迟 | 5秒 | 1至3600秒 |

`queuePrefetchLimit`只限制内存领取的持久任务数量，不限制SQLite中可以保存的待办总数。

## AList / OpenList

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 内部通信地址 | `http://alist:5244` | 必须是 HTTP 或 HTTPS URL；可以填写 AList 或 OpenList 的 WebDAV 基础地址，BFB 会自动访问其 `/dav` 路径 |
| 网页访问地址 | 空 | 可选；用于“在网盘中查看”，支持反向代理基础路径，禁止凭据、查询串和片段，推荐 HTTPS |
| 用户名 | `admin` | AList/OpenList WebDAV账号 |
| 密码 | 空 | 保存后不在日志输出 |
| 目标目录 | `/bili-backup/videos` | 必须以`/`开头；已有归档时修改请使用“迁移归档路径” |
| 目录布局 | 用户名/收藏夹/视频 | 也可选收藏夹/视频、仅视频 |
| 归档播放传输方式 | 优先网盘直连 | 可改为始终由BFB代理；直连失败会自动回退代理 |
| 远端核验并发 | 3 | 1至100 |
| 远端核验速率 | 2次/秒 | 0.5至100 |
| 每轮最多补传 | 20 | 1至1000 |

## BBDown

| 配置 | 默认值 | 可选值 |
| --- | --- | --- |
| 播放接口 | 网页 | 网页、APP |
| 画质 | 自动 | 自动、8K、4K、1080P60、1080P、720P |
| 编码偏好 | `HEVC → AVC → AV1` | 可拖动排序 `HEVC`、`AVC`、`AV1`；只影响新下载。待处理中的媒体重试可单独选择画质、编码或精确组合，不修改全局设置 |
| Hi-Res | 关闭 | 开启时必须使用APP接口 |
| 杜比 | 关闭 | 开启时必须使用APP接口 |
| 文件名模板 | `<videoTitle>-<bvid>` | 1至240字符，必须包含`<bvid>` |

APP模式要求所有启用账号都具有扫码登录得到的access token。

字段名中的 `alist` 是历史兼容命名，不限制实际服务类型。内部通信地址不要重复添加 `/dav`；如果服务部署在反向代理基础路径下，填写基础地址即可。OpenList 需要在后台为 WebDAV 用户授予目标挂载的管理权限；保存后应先做小文件 PUT、大小确认、下载和删除测试。

## 维护

| 配置 | 默认值 | 有效范围 |
| --- | ---: | --- |
| 旧命名扫描安全上限 | 10000个文件 | 100至100000 |

达到扫描上限会明确显示预览未完成，并禁止执行不完整重命名批次。

## 环境变量

部署安全和日志上限使用环境变量，包括`ADMIN_USER`、`ADMIN_PASS`、`SESSION_SECRET`、`COOKIE_SECURE`、`ALLOW_COOKIE_EXPORT`、`BFB_DEBUG_LOG_RETENTION_DAYS`、`BFB_DEBUG_LOG_MAX_FILES`和`BFB_DEBUG_LOG_MAX_MIB`。参见[安全配置](../operations/security)与[日志](../operations/logs)。
