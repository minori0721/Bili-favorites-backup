## v2.5.4

- 收口视频不可用的软终态：明确不可用时停止无意义下载重试，后台按账号相关性低频复核，视频恢复后沿用原有幂等队列，已有归档和封面不受影响。
- 统一传输会话代次、分P证据和恢复投影，失败或未知远端状态不再误标成功，也不会在本地唯一成品尚未形成可靠远端证明时自动清理文件。
- 修复已停止候选的迟到回调、空上传代次、共享任务和旧归档恢复边界；待处理只显示需要管理员决定的事项。
- 普通可用性探测只使用相关收藏账号和UP主账号，充电权限探测保留启用账号回退；迁移弹窗关闭、分页和重试不会被迟到请求覆盖。

## v2.5.3

- 重命名检查和画质升级预览优先复用SQLite中已验证的远端证明，首个响应不再等待完整远端目录扫描；后台扫描使用最多2个目录并发并通过短时缓存补充结果。
- 预览跳过项保留完整总数和按原因统计，页面只展示有限示例；画质升级目标改为批量读取，避免逐条查询SQLite。
- 扫描状态、覆盖上限和不完整结果在接口和页面中明确显示，执行阶段仍逐项重新核验远端，不把本地索引当成远端事实。

## v2.5.2

- 待处理媒体替换支持查看全部分P共同可用的画质×编码组合、分辨率、帧率、预计成品、本地峰值、缓存余量及大小来源，并可严格更换画质、编码或两者；探测失败时不自动预选回退项。
- 队列看板统一媒体替换的安全摘要和“换规格”入口，严格规格失败不再显示底层英文或不适用的直接上传操作。
- 修复在线内容接口页大小/历史游标及在线缩略图并发清理边界。

## v2.5.1

- 新增“在线内容”工作区，按账号读取在线收藏夹、订阅合集、追番追剧、稍后再看和历史；只有用户打开时请求B站，已归档BVID直接复用本地归档。
- 新增手动归档来源和SQLite schema 11；手动来源可重启恢复、进入既有上传/验证/冲突/删除状态机，不伪造B站收藏关系。
- 封面分为永久归档封面和有界在线缩略图缓存；在线缓存默认256MB按LRU淘汰，迁移包只包含归档封面。
- BBDown fork 更新至 `bfb-2.0.4`，提供不含签名播放地址的结构化媒体探测；严格画质/编码任务逐分P校验并提供空间估算，探测不可用时普通下载继续兼容旧BBDown。
- SQLite升级到`user_version 11`，JSON状态schema 13和迁移包schema 3保持不变。回滚前应恢复schema 10升级备份，不能让旧镜像直接打开schema 11数据库。

## v2.5.0

- 远端存储配置和文档补充 AList / OpenList WebDAV 支持，内置 Compose 继续使用 AList，外接 OpenList 只需填写同一组 WebDAV 配置字段。
- PUT 返回405时会复核文件是否实际落盘；归档路径迁移开始前会独立探测 COPY/MOVE，不支持 COPY 时提前阻止迁移。
- 普通归档改为持久化直接上传会话：正式路径直接PUT，不创建暂存目录，不依赖MOVE；完整旧证明优先保留，未知同大小或异大小整组进入独立候选，队列提供只读复核、一次性重传和候选选择。
- SQLite升级到`user_version 10`，schema 9保存上传会话与逐文件状态，schema 10为每次上传尝试增加持久化代际并保留旧明细；PUT已接受但暂时不可见时不自动重复传输，只有管理员明确继续上传才允许一次重传。
- BBDown fork 更新至 `bfb-2.0.2`，固定源码提交和发布ZIP校验值；从 `bfb-2.0.1` 升级时，配置不变的 WEB 未完成轨道继续续传，APP 未完成轨道隔离后重新下载。

## v2.4.6

- 删除账号可选择仅移除登录或清理该账号远端归档；默认保留归档，危险模式需预览并输入固定确认文字。
- 归档库支持按具体历史、停用或已移除账号来源删除归档，活动收藏关系仍禁止删除；新增已移除账号目录和已删除筛选。
- 远端删除使用持久任务、全量HEAD预检、物理路径去重、共享保留、逐文件确认、重启恢复和三档退避，未知文件不会递归删除。
- SQLite升级到`user_version 7`；schema 1至6升级前生成一致性备份和SHA256摘要，JSON兼容状态仍为schema 13，迁移包仍为schema 3。
- 普通UGC的APP解析配套迁移到BBDown PlayerUnite，合并AVC、HEVC和AV1结果；单个编码失败不影响其他成功流，全部空流继续触发现有APP到WEB回退。
- APP最高仅480P或低于明确请求的B站档位时查询一次WEB；只合并更高的WEB视频，保留APP普通、杜比和Hi-Res音频，WEB失败继续使用APP结果。
- BFB为每个账号生成独立稳定的APP设备标识，通过私有临时配置传给BBDown且不写入WEB Cookie。
- `v2.4.6`固定BBDown fork Release `bfb-2.0.1`、源码提交和发布ZIP校验值；`v2.4.5`镜像继续使用`bfb-2.0.0`，历史行为不变。
- 升级后，配置未变化的WEB未完成轨道可续传；APP旧未完成轨道会隔离并重新下载，避免继续复用可能仅480P的半成品。
- 归档导航、删除进度和共享路径核验改为批量SQLite查询；管理弹窗统一层级、键盘焦点和返回位置，修复快速双击删除、搜索竞态及手机归档库偏移。
- 根生产依赖审计为10项（3项低危、3项中危、4项高危、0项严重），文档站生产依赖审计为0项；没有使用破坏性强制降级处理上游告警。

### 升级说明

- SQLite schema 1至6首次升级到`user_version 7`前会生成一致性备份和SHA256摘要；JSON兼容状态仍为schema 13，迁移包仍为schema 3。
- `v2.5.0`使用schema 10：schema 9保存上传会话，schema 10增加上传代际并保留旧尝试明细；升级会生成一致性备份，不创建远端暂存目录，不自动移动或删除已有远端文件。确认阶段的远端409会进入带代际的人工恢复，不会无限普通重试。
- 从`v2.4.6`升级到schema 10前会生成一致性SQLite备份；回滚必须恢复升级前备份，不能让旧镜像直接打开schema 10数据库。
- 发布前根生产依赖审计为11项（2项低危、3项中危、6项高危、0项严重），文档站生产依赖审计为0项；未执行破坏性强制修复。
- 归档删除开始后不可取消；升级前应确认没有等待执行、执行中、自动重试或失败待人工处理的删除任务。

## v2.4.5

- 新增只读取本地SQLite的归档库，支持全局、账号、当前收藏夹与停用收藏夹浏览、搜索、筛选、稳定分页和连续播放。
- 下架清单改为SQLite服务端筛选和键集分页，两个标签独立缓存；历史封面使用安全、低速、一次性的后台回填。
- 新下载同时保存BBDown实际选择的B站档位和ffprobe媒体参数；画质升级与普通上传共用同一份持久清单证明，预检失败不会替换旧归档。
- 播放器显示真实直连或代理状态、实际尺寸与编码，并可通过独立配置的 AList / OpenList 网页地址打开对应文件。
- 非标准分辨率按真实短边显示；播放器区分网络、解码和HEVC兼容错误，解码失败不再无意义地切换BFB代理。
- 收紧归档路径删除竞态、播放重定向、Windows进程关闭及封面任务生命周期，异常中断后优先恢复人工复核状态。
- 根生产依赖审计为10项（3项低危、3项中危、4项高危、0项严重），文档站生产依赖审计为0项；未使用破坏性依赖降级处理上游告警。

### 升级说明

- SQLite升级到`user_version 6`；schema 1至5首次升级前会生成一致性备份和SHA256摘要，JSON兼容状态仍为schema 13，迁移包仍为schema 3。
- 回滚到`v2.4.4`或更早镜像时必须恢复升级前SQLite备份，不能让旧镜像直接打开schema 6数据库。
- 本次升级不会批量探测、下载、转码或重命名旧归档；旧文件的实际媒体参数只会在浏览器成功读取后按现有规则补齐。

### 已知事项

- APP接口在部分账号或视频上可能只返回480P播放流，但BBDown仍会完成下载并被当前流程视为成功。关闭Hi-Res和杜比时暂建议使用WEB接口；APP结果识别与安全自动回退计划后续修复。

## v2.4.4

- 收藏夹详情新增AList归档播放器，支持分P、连续播放、进度恢复、全量队列、搜索、手机沉浸竖屏、全屏和画中画。
- 播放器优先使用经过BFB校验的网盘HTTPS临时直链，无法安全直连时自动回退流式代理；播放文件仍需通过登录、收藏关系和远端证明校验。
- 已同步收藏夹详情统一从SQLite分页读取，已上传后失效的视频继续显示归档前标题、封面和准确状态。
- 管理员登录改用独立SQLite持久Session，普通会话最长24小时，可主动选择固定保持30天；队列轮询不会滚动续期或写Session库。
- `artplayer`固定为5.4.0，`archiver`升级到8.0.0；根生产依赖审计为10项（3项低危、3项中危、4项高危），文档站为0。

### 升级说明

- SQLite继续使用`user_version 5`，JSON兼容状态继续使用schema 13，迁移包继续使用schema 3。
- 从`v2.4.3`及更早版本更新后需要重新登录一次，之后可在登录页选择固定保持30天。
- 会话库位于`data/auth-sessions.sqlite`且不进入迁移包；修改管理员账号、密码或`SESSION_SECRET`会撤销已有会话。
- 播放器不转码，HEVC依赖浏览器和设备原生解码；直连临时签名URL会出现在当前浏览器的网络面板中。

## v2.4.3

- 新增AList归档路径安全迁移：同一挂载内扫描整个旧目录，使用不覆盖的WebDAV COPY、延迟可见确认和SQLite持久进度。
- 迁移完成前调度器保持维护锁；切换后旧目录默认保留，清理必须重新核验并输入`DELETE OLD ARCHIVE`。
- 旧格式画质任务和无清单缓存改为一次性启动检查，完成后不再反复枚举任务或读取`temp`目录。

### 升级说明

- SQLite schema 1至4会在升级前生成一致性备份和SHA256摘要，再自动升级到`user_version 5`。
- JSON兼容状态继续使用schema 13，迁移包继续使用schema 3。
- 升级不会自动移动现有归档；只有完成迁移预览、COPY和远端确认后才会切换目标路径。
- AList `v3.61.0`下天翼驱动的COPY延迟和目录删除行为尚未经过真实部署验证，首次使用应选择测试目录并保留旧目录。
